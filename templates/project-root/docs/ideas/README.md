# Ideas

Exploratory architecture discussions and design artifacts. Ideas are where **alternatives get weighed** — the only stage in FBS where competing approaches belong.

An idea doc is finished when it records a **single chosen direction** and why the others were rejected. The plan that follows carries forward only the decision.

## Workflow

1. Explore via `/new-idea` — reports the assigned `IDEA-NNN`
2. (Optional) Review via `/review-idea-doc` — confirms a direction was actually chosen
3. If contract changes are needed: progress to `/new-plan` (Tier 3)
4. If implementation-only: progress straight to `/new-sprint` (Tier 2)

If the idea needs more than one sprint's worth of work, note the split — each piece becomes its own plan and its own sprint.

## Naming convention

Files use sequential numbering: `IDEA-NNN-YYYY-MM-DD-<topic>.md` (e.g., `IDEA-001-2026-03-13-user-authentication.md`). The `/new-idea` skill assigns the next available number automatically.
